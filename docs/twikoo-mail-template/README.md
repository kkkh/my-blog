# Twikoo 邮件通知模板（适配茗辰原博客 · 白天模式）

Twikoo **1.7.19** 邮件通知模板，配色适配本站主题（浅绿背景 `#f2f5ec` + 深蓝/蓝强调色 + 圆角卡片 + 科技感按钮），**白天模式风格**。

## 配置位置

登录 Twikoo 管理后台（`https://twikoo.mingcy.cn` → 评论管理 → 设置 → 邮件通知）：

| 配置项                | 值                                   | 说明               |
| --------------------- | ------------------------------------ | ------------------ |
| `MAIL_TEMPLATE_ADMIN` | `notify-admin.html` 内容             | 新评论时通知博主   |
| `MAIL_TEMPLATE`       | `notify-reply.html` 内容             | 回复时通知被回复者 |
| `MAIL_SUBJECT_ADMIN`  | `茗辰原：文章有新评论了`             | 博主通知邮件主题   |
| `MAIL_SUBJECT`        | `${PARENT_NICK}，您的评论收到了回复` | 回复通知邮件主题   |

> 模板中的 `${...}` 是 Twikoo 变量占位符（运行时替换），**不要改动**；其余 HTML 可自由调整。

## 模板变量（1.7.19 源码 `utils/notify.js` 确认）

### 博主通知（`MAIL_TEMPLATE_ADMIN`）

| 变量           | 含义                     |
| -------------- | ------------------------ |
| `${SITE_NAME}` | 博客名称（管理后台配置） |
| `${SITE_URL}`  | 博客地址                 |
| `${NICK}`      | 评论者昵称（已转义）     |
| `${IMG}`       | 评论者头像               |
| `${MAIL}`      | 评论者邮箱（已转义）     |
| `${IP}`        | 评论者 IP                |
| `${COMMENT}`   | 评论内容                 |
| `${POST_URL}`  | 文章评论链接（带锚点）   |

### 回复通知（`MAIL_TEMPLATE`）

| 变量                           | 含义                   |
| ------------------------------ | ---------------------- |
| `${SITE_NAME}` / `${SITE_URL}` | 博客名称 / 地址        |
| `${PARENT_NICK}`               | 被回复者昵称（已转义） |
| `${PARENT_IMG}`                | 被回复者头像           |
| `${PARENT_COMMENT}`            | 被回复的评论内容       |
| `${NICK}`                      | 回复者昵称（已转义）   |
| `${IMG}`                       | 回复者头像             |
| `${COMMENT}`                   | 回复内容               |
| `${POST_URL}`                  | 回复链接（带锚点）     |

> 注：`${COMMENT}` / `${PARENT_COMMENT}` 官方未转义（与默认模板一致），模板中仅作文本展示，勿拼接进 href 等属性。

## 使用

1. 打开对应 `.html` 文件，**全选复制全部内容**
2. 粘贴到管理后台对应配置项，保存
3. 设置页底部可点「发送测试邮件」验证

模板基于 table 内联样式（兼容 Outlook / Gmail / QQ 邮箱等主流客户端），无外部依赖。

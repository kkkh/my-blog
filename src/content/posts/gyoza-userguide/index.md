## 前言

Gyoza 是一款兼顾性能与美观的 Astro 博客主题。为了获得最佳的使用体验，请在开始前确保你已具备基础的终端操作能力与 Git 知识。

## 前置条件

在运行 Gyoza 之前，请确保你的本地开发环境满足以下要求：

- **Node.js**：版本 `>= 18.18.0`（建议使用 LTS 版本，可通过 [Node.js 官网](https://nodejs.org/) 下载）
- **pnpm**：版本 `> 8.1.0`（本项目强烈推荐使用 pnpm 进行包管理。如未安装，请运行 `npm install -g pnpm` 进行全局安装）

## 快速开始

### 1. 克隆仓库

登录 GitHub 账号，访问 [lxchapu/astro-gyoza](https://github.com/lxchapu/astro-gyoza)，点击右上角的 **Fork** 按钮，将项目派生到你自己的账号下。

随后复制你派生仓库的 HTTPS 或 SSH 地址，在终端中执行以下命令克隆到本地：

```sh
git clone <你的仓库地址>
cd astro-gyoza
```
